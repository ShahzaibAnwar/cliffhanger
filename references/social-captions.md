# Social captions

Write `out/captions.md` after the final render. Base everything on the actual script and
`facts.md`. Each block is ready to paste. Tease the cliffhanger; never give away Part 2.

## Universal rules

- Line 1 = a hook that works without the video (it shows in feeds/notifications before "more").
- Use the topic's search words naturally in the first 2 lines (platform search is keyword-driven now).
- One clear CTA per platform (follow for Part 2 / save / share with someone / comment answer).
- Hashtags: few and specific (topic + niche + series tag). No banned or irrelevant tags.
- Health/science: keep claims as hedged as the video ("commonly cited", "one theory").
- Write in the same language/register as the VO unless the user asks otherwise.

## Platform specs

| platform | length | hashtags | notes |
|---|---|---|---|
| Instagram Reels | ≤ 2,200 chars; first ~125 visible | 3–5 at the end | hook line, 2–4 short lines with line breaks, CTA "Follow for Part 2", question to drive comments |
| TikTok | ≤ 4,000 chars; keep 150–300 | 3–5 | keyword-rich first sentence (TikTok search), conversational, end with question |
| YouTube Shorts | title ≤ 100 (aim < 60); description ≤ 5,000 | 3 in description (first 3 show above title) | title = curiosity + keyword; description: 2–3 lines + sources + series playlist line |
| Facebook Reels | 1–3 short lines | 1–3 | question that invites opinions/stories ("Has this happened to you?") |
| X / Twitter | ≤ 280 chars | 0–2 | one punchy line + the twist teased; video attached |
| LinkedIn | 600–1,300 chars | 3 | lesson framing: what this teaches about the brain/body/systems; professional tone; no clickbait caps |
| Threads | ≤ 500 chars | 1 topic tag | casual, opinionated, question at the end |
| Pinterest (optional) | title ≤ 100, description ≤ 500 | keywords instead of tags | evergreen, searchable phrasing |
