AI illustrations

Free image generation for the drawings in your reels. Images are made once per project and reused. Without a key, the skill uses its hand-drawn vector art instead.

Cloudflare Workers AI free ~170 images/day

Uses FLUX.1 schnell. In the Cloudflare dashboard, go to AI → Workers AI → "Use REST API". Copy your Account ID and create an API token with the "Workers AI" permission.

Google Gemini paid · billing required

"Nano Banana" (Gemini Flash Image) is best for keeping one object consistent across scenes. Image models currently have no free quota, so turn on billing in aistudio.google.com. The cost is a few cents per image. Use Cloudflare for free images.
